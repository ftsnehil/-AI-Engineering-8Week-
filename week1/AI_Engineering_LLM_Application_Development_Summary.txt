1. WHAT IS AN LLM?
------------------
LLM = Large Language Model.

It is an AI model that can understand and generate human language.

Examples:
- GPT
- Gemini
- Claude
- Llama
- Mistral

Example:

Resume + Question
       ↓
      LLM
       ↓
    Answer


2. WHAT IS GENERATIVE AI?
-------------------------
Generative AI means AI that can generate new content.

It can generate:
- Text
- Code
- Summaries
- JSON
- Images
- Other content

Example:

You: "Write Java code to reverse a string."
                    ↓
                   AI
                    ↓
              Java code generated


3. WHAT IS AN API?
------------------
API = Application Programming Interface.

In simple words:

An API allows your program to communicate with another software/service.

Your Python Program
        ↓
       API
        ↓
      LLM
        ↓
      API
        ↓
Your Python Program

Code such as:

response = client.chat.completions.create(...)

means your Python program is asking the AI model for a response.


4. HOW YOUR RESUME PROJECT WORKS
--------------------------------

PART 1 — UNDERSTAND THE JOB
---------------------------
You have a job description.

You send it to the LLM.

The LLM extracts structured information such as:
- Role
- Required skills
- Preferred skills
- Experience
- Education
- Responsibilities

Flow:

Job Description
      ↓
     LLM
      ↓
Structured Job


PART 2 — UNDERSTAND EACH RESUME
--------------------------------
Your resumes are stored in a folder:

resumes/
    resume1.pdf
    resume2.pdf
    resume3.docx
    ...

Python finds the files and reads them.

Then the resume text is sent to the LLM.

The LLM extracts:
- Name
- Email
- Phone
- Experience
- Skills
- Education
- Projects
- Certifications

Flow:

Resume PDF/DOCX
      ↓
Python extracts text
      ↓
     LLM
      ↓
Structured Resume


PART 3 — COMPARE JOB AND RESUME
--------------------------------
Your code does:

result = final_score(job, parsed_resume)

The LLM receives:

JOB DESCRIPTION
       +
CANDIDATE RESUME
       ↓
      LLM
       ↓
Score + Details

The AI checks:
- Matching skills
- Missing important skills
- Whether experience requirement is met
- Overall match percentage
- Final verdict


PART 4 — RANK CANDIDATES
------------------------
The score for every candidate is stored.

Example:

Kshitij  → 91
Priya    → 88
Rahul    → 82
Aman     → 67

Python sorts them from highest to lowest:

Kshitij  → 91
Priya    → 88
Rahul    → 82
Aman     → 67

Then your program can select the TOP 2 and LOWEST 2.
